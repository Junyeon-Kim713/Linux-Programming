| 기능 | 단축키 |
| :--- | :--- |
| **문자단위 커서이동 -> 앞, 뒤, 맨앞, 맨뒤** | `Ctrl + b` (앞), `Ctrl + f` (뒤), `Ctrl + a` (맨앞), `Ctrl + e` (맨뒤) |
| **단위단위 커서 이동 -> 앞, 뒤** | `Alt + b` (앞 단어), `Alt + f` (뒤 단어) |
| **현재 위치 문자 삭제** | `Ctrl + d` 또는 `Delete` |
| **뒤에 있는 문자 삭제** | `Ctrl + h` 또는 `Backspace` |
| **뒤에 있는 단어 삭제** | `Ctrl + w` (커서 앞 단어 삭제) / `Alt + d` (커서 뒤 단어 삭제) |
| **자르기 및 붙여넣기** | `Ctrl + k` (커서 뒤 자르기), `Ctrl + u` (커서 앞 전체 자르기), `Ctrl + y` (붙여넣기) |
| **화면 잠금 및 해제** | `Ctrl + s` (화면 출력 잠금), `Ctrl + q` (잠금 해제) |
| **실행종료** | `Ctrl + c` (현재 프로세스 강제 종료) |
| **화면삭제** | `Ctrl + l` (터미널 화면 지우기) |
